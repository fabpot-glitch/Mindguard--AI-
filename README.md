## 📌 Overview

MindGuard AI is a privacy-first intelligent system that detects **focus levels, distractions, and cognitive fatigue** in real-time.

Unlike traditional productivity tools, it analyzes **actual attention and behavior**, not just time spent.

---

## ✨ Key Features

* 👁️ Real-time face & gaze tracking
* 📱 Phone distraction detection
* ⏸️ Auto pause when distracted
* 📊 Focus analytics dashboard
* 🔥 Burnout risk prediction
* 🎯 Focus score system
* 🏆 Gamification (XP, streaks)
* 🔒 Privacy-first (no video storage)

## 🚀 Getting Started

### 1️⃣ Clone Repo

git clone https://github.com/fabpot-glitch/Mindguard--AI-.git
cd Mindguard--AI-

### 2️⃣ Install

npm install

### 3️⃣ Environment Setup

Create `.env`

VITE_BACKEND_URL=https://nikhitha-nikhi12-mindguard-backend.hf.space/

### 4️⃣ Run

npm run dev
